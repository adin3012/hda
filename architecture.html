How to Proceed — Phase-by-Phase Action Plan
HDA is currently in Phase 1 (static website, building phase)
Phase 1 — Right Now (INR 0–5k)
Complete and Launch the Static Site
Validate demand before spending on development. Use no-code tools to collect first revenue.
1
Replace YOUR_GOOGLE_FORM_LINK in js/main.js with your actual Google Form URL
2
Buy domain (hdacoaching.in ~INR 900) and deploy to Netlify or GitHub Pages
3
Set up a Razorpay Payment Link for each coaching package. No backend needed — share via WhatsApp
4
Connect your real Calendly link into the modal. Set your availability for 1:1 sessions
5
Add Google Analytics 4 to the site. You need traffic data before deciding where to invest
Phase 2 — Months 3–8 (INR 1.5L–2.5L)
Build the Platform After First Revenue
Do not start Phase 2 development until you have earned INR 1L+ from Phase 1 clients. That revenue funds the build.
1
Sell first 5–10 coaching packages manually. Use Razorpay link + Zoom + WhatsApp. Confirm people pay.
2
Record 3–5 course modules. Sell via Razorpay link + Google Drive delivery. Validate course demand.
3
Hire a full-stack freelancer (Upwork / LinkedIn). Budget INR 1.4L–2.2L for the full build per the cost table above.
4
Set up Supabase (DB), Railway (API), Vercel (frontend), R2 + BunnyCDN (video). Use free tiers first.
5
Launch with 1 course + 1:1 coaching. Do not wait for a perfect product — ship and iterate.
Shortcut Bridge (Optional)
No-Code LMS While Platform is Being Built
If you cannot wait 3–4 months for a custom build, use Teachable as a bridge. Go live in one week.
A
Teachable — Full LMS with video, quizzes, certificates, Razorpay. INR 3,500–7,000/mo. Launch in 1 week. No dev needed.
B
Kajabi — Courses + email marketing + community + website builder. INR 11,000–25,000/mo. Best all-in-one for a coaching business.
C
Custom Platform — Full control, lower long-term cost, own branding. INR 1.5L–2.5L one-time. 3–4 months build.
Recommendation: Use Teachable as a bridge to start earning while the custom platform is being built. Migrate students once the custom build is live.

Notes: All INR figures are estimates as of April 2025. Development cost assumes a single experienced full-stack freelancer from the Indian market (Hyderabad, Bangalore, or remote). Agency rates are 2x–4x higher. Razorpay transaction fee (2%) is variable and excluded from monthly infra totals. Migrate to dedicated infrastructure only when monthly revenue exceeds INR 3L consistently.
